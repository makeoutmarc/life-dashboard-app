# Life Dashboard App

Persoenliche iPhone-App fuer Gesundheit, Fitness, Finanzen und Produktivitaet.

## Ziel

Die App soll als privates Life Dashboard dienen:

- Tages- und Wochenstatus sehen
- Gym- und Makro-Ziele tracken
- Disziplin-Score berechnen
- spaeter Aktien, Barcode-Scanner und weitere Analysen ergaenzen

## Technische Richtung

Wir bauen die App pragmatisch mit Expo, React Native und TypeScript.

Start ohne Backend:

- Daten bleiben zuerst lokal auf dem Geraet
- MVP vor Perfektion
- Schrittweise Erweiterung

## MVP

1. Dashboard mit Tagesstatus
2. Gym-Check-in
3. Manuelles Makrotracking
4. Wochenuebersicht
5. Disziplin-Score
